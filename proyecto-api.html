Desarrollo Web — 2024 — API pública

API REST con documentación profesional

Node.js + ExpressPostgreSQL + RedisJWT + API KeysSwagger / Redoc

API con utilidad real, no un CRUD de ejemplo. Respuestas en menos de 120 ms p95, con errores trazables, versionado y documentación que un tercero puede usar sin preguntar.

Qué resuelve

Consulta de datos financieros/meteorológicos con filtros, paginación por cursor y campos seleccionables. Cada respuesta incluye metadatos de paginación y enlaces para la siguiente página, sin exponer offsets frágiles.

Autenticación

  • JWT con access corto y refresh rotativo
  • API keys por proyecto, revocables y con scopes
  • Cabeceras y logs por key para auditoría
  • Rotación sin downtime

Protección

  • Rate limiting token bucket en Redis
  • Quotas mensuales y burst por plan
  • Cabeceras estándar RateLimit-*
  • Bloqueo progresivo ante abuso

Stack y contrato

Node.jsExpressPostgreSQLRedisJWTSwaggerOpenAPI 3.1Redoc

Documentación viva

OpenAPI generado desde el código. Swagger UI para probar, Redoc para leer y colección Postman versionada. Ejemplos en cURL, JS y Python que realmente funcionan copiando y pegando.

Operación

Versionado /v1, errores con código, mensaje humano y traceId. Logs estructurados en JSON y métricas de latencia por endpoint para detectar regresiones.

Uso real

Pensada para que otro equipo la integre sin soporte. Códigos de error documentados, cambios con changelog y deprecaciones con fecha. Un cliente puede generar su API key, probarla en Swagger y pasar a producción el mismo día.
